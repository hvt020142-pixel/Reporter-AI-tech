## 3. Agent & ứng dụng

**(a) [MỚI, cạnh tranh coding agent] Meta chính thức ra mắt Muse Code — agent lập trình dạng terminal (bản beta, chạy trên macOS/Linux) chạy bằng mô hình mới Muse Spark 1.2 của Meta Superintelligence Labs — công cụ coding-agent đầu tiên của Meta cạnh tranh trực tiếp với Claude Code và Codex.** Muse Code có thể điều phối nhiều "subagent" bền vững (persistent subagent) cho từng nhiệm vụ, xử lý các thay đổi trên toàn bộ repository lớn: lập kế hoạch, viết mã, xác thực kết quả. Điểm kỹ thuật đáng chú ý: một log sự kiện cục bộ (local event log) ghi lại mọi lệnh gọi mô hình, lượt chạy công cụ, phê duyệt và chỉnh sửa — giúp runtime "replay chính xác" và an toàn khi khởi động lại (restart-safe): sau khi crash, agent tiếp tục đúng nơi đã dừng [30][31][32][33]. So với Codex của OpenAI (đã chạy song song nhiều agent trên đám mây), lợi thế của Muse Code nằm ở runtime chống crash và thiết kế subagent, chưa rõ mức độ cạnh tranh thực tế với thị phần Claude Code/Cursor đã nêu ở báo cáo 05/08 (Claude Code tăng trưởng gấp 6 lần trong 9 tháng, 46% lập trình viên cấp cao chọn dùng).

**(b) [MỚI, agent duyệt web] Startup Hark — từng gọi vốn Series A 700 triệu USD hồi tháng 5 — công bố xem trước (preview) Hark Handoff, agent điều khiển trình duyệt để hoàn tất tác vụ trên các website KHÔNG có API chính thức (Target, Walmart, OpenTable, LinkedIn...).** Handoff phân tích cấu trúc trang và dữ liệu hình ảnh để quyết định click/điền form, vận hành trên một máy tính ảo riêng; công ty công bố đạt 97,7% trên benchmark Online-Mind2Web — vượt nhẹ mức dẫn đầu trước đó — với mức giá API 0,18 USD/2,37 USD trên mỗi triệu token (đầu vào/đầu ra), rẻ hơn đáng kể so với 5 USD/30 USD của GPT-5.5 [34][35].
